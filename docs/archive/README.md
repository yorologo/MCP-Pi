# Historical evidence

This directory contains selected historical evidence that is still useful for audit, provenance or understanding the reference appliance. It is **not** current operating guidance.

Retained evidence:

- `inventory/baseline-2026-09-08.md` — dated hardware/system baseline;
- `migration/pre-migration-inventory.md` — state captured before the OS migration;
- `tunnel-client-provenance.md` — provenance/build evidence for the external tunnel client;
- `v1-acceptance.md` — historical v1 acceptance evidence.

Completed runbooks, implementation plans/specifications, old architecture descriptions and per-release Markdown notes are intentionally absent from HEAD. Git history preserves them when historical reconstruction is required.

Use the root `README.md` and the six `docs/*.md` guides for current behavior.

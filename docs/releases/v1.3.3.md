# MCP-Pi Gateway 1.3.3

**Release date:** 2026-09-16

## Summary

1.3.3 completes the Admin Console surface for the Grant model already present in the Registry and Policy Engine. No Registry schema, Tool Catalog, MCP protocol or authorization semantics change.

## Added

- **AI Clients → Grants** page for each registered client.
- Create, edit, enable/disable and delete grants using the existing Registry CRUD methods.
- Target/Project scope validation and known-capability validation.
- Explicit confirmation for fully global `* / * / *` grants.
- **Check Effective Access**, which calls the existing `authorize_client()` Policy Engine and reports the actual allow/deny result.
- Audit records for grant creation, update, toggle, deletion and effective-access checks.

## Security / compatibility

- Deny-by-default, kill switches, Project read/write policy and trusted Target-shell semantics are unchanged.
- Grant administration remains authenticated and protected by the Admin Console's existing CSRF middleware.
- Cross-client grant manipulation fails closed.
- Existing specific or comma-separated capability strings remain readable/editable; the UI validates every token against the capabilities already known by the Core.
- Direct SQLite editing is no longer needed for normal Grant administration.

## Verification

Release publication requires the full local gate, CI on `develop` and `main`, deterministic ARMv6 packaging from the immutable `v1.3.3` tag, and post-release deployment/Doctor acceptance on the same SHA.
